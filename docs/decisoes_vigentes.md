# CUT · Decisões vigentes da coordenação

Fonte única das decisões que valem para todos os agentes, skills e conversas. Atualizado em 24/11/2026.

Como usar:
- Leia este arquivo antes de trabalhar. Ele fica em `referencia/decisoes_vigentes.md` na pasta CUT_coordenacao (a ponte copia do repositório a cada rodada) e em `docs/decisoes_vigentes.md` no repositório.
- Se uma skill, uma tarefa agendada ou um documento antigo disser outra coisa, vale este arquivo. Diga a divergência no relatório.
- Os vetos e alterações recentes de `decisoes_recentes` (no pacote de entrada) também valem; quando viram regra geral, entram aqui.
- Só a coordenação muda este arquivo. Decisão nova entra com a data.

## Questões e testes

| Data | Decisão |
|---|---|
