# Livros-texto: índice por capítulo (v0.3)

`catalogo_livros_v0.3.csv` mapeia capítulos de Sabiston 20, Trauma 9ed (Feliciano/Mattox/Moore), Cirurgia do Trauma (Birolini), Doença Trauma e ATLS 11 aos temas T001–T150 (camada 2, livro-texto).
- Páginas são do PDF (não do livro impresso). Mapeamento tema↔capítulo é sugestão: o curador confirma.
- **ATLS 11**: os direitos do ACS proíbem enviar o conteúdo a aplicativos/plataformas de terceiros. Uso `consulta_humana_restrita`: só o índice; o texto NÃO entra no carregador nem no executor.
- Texto integral dos livros nunca vai ao GitHub (direitos autorais); só este índice.
